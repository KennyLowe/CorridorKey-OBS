# corridorkey-obs: CorridorKey live keying filter for OBS Studio

A native OBS Studio video filter ("CorridorKey") that keys a green-screen source live with
[CorridorKey](https://github.com/nikopueringer/CorridorKey) by Corridor Digital, running a
TensorRT engine on the source's own GPU textures. Windows 11, NVIDIA RTX (Ampere or newer).
v1 targets the owner's two machines only (see `../docs/INSTALL.md`).

Powered by CorridorKey by Corridor Digital (CC BY-NC-SA 4.0). Not affiliated.

## Build

Scaffolded from [obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate) (master at
commit `3e7d7ac`, 2025-12-09). The template's pinned OBS tag is kept: headers and `libobs` are
built from **OBS Studio 31.1.1** sources (`buildspec.json`); the plugin runs on OBS 32.2.2.

Requirements: Visual Studio 2022 (MSVC 14.44, Windows SDK 10.0.22621), CMake >= 3.28, CUDA 12.9
toolkit, TensorRT 10.16.1.11 for CUDA 12.9 unpacked at `C:\TensorRT-10.16.1.11`.

```powershell
.\scripts\build.ps1          # configure + build + ctest (unit and GPU suites)
.\scripts\install.ps1        # copy to C:\ProgramData\obs-studio\plugins\corridorkey-obs\
```

Changes from the template: renamed to `corridorkey-obs`; Qt and the frontend API stay off;
MSVC-only compile flags in `cmake/windows/compilerconfig.cmake` are limited to C/C++ so nvcc can
compile the CUDA sources; `cmake/FindTensorRT.cmake`, Catch2 tests and `scripts/` added.

## Layout

| Path | What |
|---|---|
| `src/plugin-main.cpp` | module load, filter registration |
| `src/ck-filter.cpp` | the OBS filter: properties, render-thread frame path, fallback |
| `src/worker.cpp` | per-filter inference thread (hint, preprocess, TensorRT, postprocess) |
| `src/core/` | pure C++ logic, unit-tested: state machine, scheduler ring, stats, cache key, Auto |
| `src/gpu/` | CUDA kernels, TensorRT runner, D3D11-CUDA interop |
| `data/` | effects, locale, `perf-table.json` (generated by `ckbench perf-table`) |
| `tests/` | Catch2 unit + GPU tests, `e2e/` pytest suite driving real OBS over obs-websocket |
