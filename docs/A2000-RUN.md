# Running the benchmark on the RTX A2000 (feature 002, US1)

Feature 001 measured CorridorKey on the RTX 3060 only. Its RTX A2000 figures are **estimates**
(x1.25–1.59 of the 3060), and an estimate must be confirmed on the card before the plugin is
relied on. This page is the exact procedure for the production machine. The result becomes the
A2000 row of the plugin's Auto table (`plugin/data/perf-table.json`).

Prerequisites are in [issue #2](https://github.com/KennyLowe/CorridorKey-OBS/issues/2): the driver,
Git, uv, ffmpeg 7.1.1 and TensorRT, all from **direct downloads with hash checks (no winget or
choco)**. Do that first. Run everything below in PowerShell.

## 1. Check and record the driver

```powershell
nvidia-smi --query-gpu=name,driver_version --format=csv
```

- It must show **NVIDIA RTX A2000** (or `RTX A2000 12GB`) and a driver **≥ 576**. Write the
  version down; the run records it too.
- **If the driver is lower than 576: stop here and tell Kenny.** The pinned PyTorch (cu128) needs
  it. The choice is between updating the driver and pinning older wheels, and that's an owner
  decision.

## 2. Get the code at the release tag

```powershell
git clone https://github.com/KennyLowe/CorridorKey-OBS C:\git\corridorkey   # skip if already cloned
cd C:\git\corridorkey
git fetch --tags
git checkout v0.1.0-rc.1
```

The tag matters: the default branch doesn't have the model manifest or the plugin's helper
commands until the feature-002 pull request is merged.

## 3. Set up the benchmark environment

```powershell
cd C:\git\corridorkey\bench
.\setup.ps1
```

`setup.ps1` clones CorridorKey at the pinned commit, downloads the official weights
(`models/manifest.json`: Hugging Face `nikopueringer/CorridorKey_v1.0`, sha256 `74d614f7…b20b`,
checked), runs `uv sync` and checks CUDA and NVENC. It should end by printing
`torch … NVIDIA RTX A2000` and a working `h264_nvenc`.

Optional but recommended: copy the Hollywood Camera Work plates ("Locked Backdrop", "Godiva
Close") into `C:\git\corridorkey\footage\hcw\<name>\` as PNG sequences (see `bench/README.md`).
Without them, the quality step uses only the three public clips.

## 4. Run the benchmark (about 6 hours)

Close OBS and anything else that uses the GPU, and stop the machine from sleeping. Then:

```powershell
cd C:\git\corridorkey\bench
uv run ckbench all
```

It writes `bench/results/<run-id>/results.json` and a draft `REPORT.md`. The run id is printed at
the start (`run_id 2026…`).

- Exit code 0 means it's complete; 2 means partial (some configuration ran out of memory or
  failed to export; that is recorded and is a valid result).
- Quality review: the draft report lists pending owner verdicts. Review the comparison material in
  `outputs\compare\index.html` and record each verdict with
  `uv run ckbench --run-id <run-id> review --config <id> --clip <id> --verdict pass|fail`.
  Then `uv run ckbench --run-id <run-id> report` writes the final report. If you prefer not to
  review on that machine, skip this: the draft is enough for the speed envelope, because the
  owner already accepted quality at every setting on the 3060 (`perf-table` uses speed plus
  "not failed").

## 5. Regenerate the Auto table

```powershell
cd C:\git\corridorkey\bench
uv run ckbench perf-table
```

`plugin/data/perf-table.json` now has an `NVIDIA RTX A2000…` entry next to the RTX 3060 one.

## 6. Commit the results on a branch

```powershell
cd C:\git\corridorkey
git switch -c a2000-run
git add bench/results plugin/data/perf-table.json
git status            # only bench/results/<run-id>/ and perf-table.json; no outputs/, footage/ or weights
git commit -m "bench: RTX A2000 run <run-id>"
git push -u origin a2000-run
```

Push the branch, or zip `bench\results\<run-id>\` and send it.

## 7. Afterwards (any session)

- Add the measured vs estimated comparison below.
- Rebuild the plugin release with the new `perf-table.json` so Auto picks the A2000's own measured
  settings. Until then, Auto on the A2000 treats it as an unknown GPU and uses the fastest setting
  (512×512) with a warning (FR-015).
